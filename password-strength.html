    How this estimate works

    Entropy is estimated as length × log2(character set size) -- a rough, standard way to measure how many guesses a brute-force attacker would need in the worst case. The crack-time estimate assumes an attacker can try 10 billion guesses per second against a fast, unsalted hash -- a realistic ballpark for modern offline cracking hardware, not an exact promise.

    This is a simplified model. It doesn't know if your password is a real dictionary word (which real attackers try first) unless it matches one of the common patterns flagged below -- so a long, "random-looking" but common phrase can score better here than it would against a real attacker using a dictionary-based attack.
