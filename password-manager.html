🔐 Local Password Manager

A command-line password manager written in Python with real AES-256-GCM encryption behind a master password -- no plaintext ever touches disk.

The actual tool is a Python command-line app -- init a vault, add/get/list/delete entries, all behind a master password. It uses AES-256-GCM for authenticated encryption and PBKDF2-HMAC-SHA256 with 480,000 iterations to turn the master password into the encryption key, via the audited cryptography Python library -- no hand-rolled crypto.

Try the same encryption, live, in your browser

This demo runs the same algorithm family -- AES-256-GCM with a PBKDF2-derived key -- using your browser's native SubtleCrypto API. It's real encryption happening on your device right now, not a simulation, though it's a standalone demo, not the actual vault file format above.
