About this lab

Why this site exists

This is a working log of cybersecurity projects, organized into three areas: defensive security (blue team), building security tools from scratch, and white-hat / offensive security education in safe, sandboxed environments only.

Each project on this site is labeled honestly: Live means real, working code with a demo you can try right here. Coming Soon means planned but not built yet. In Progress (hands-on) means it needs physical hardware or a real lab environment to set up -- those get written up here once they're actually done, not before.

Nothing on this site targets, scans, or tests systems without authorization. Home network tools only ever run on this lab's own network; any offensive-security work happens exclusively on sandboxed platforms built for that purpose (like VulnHub and Hack The Box), never against real third-party systems.
